# 家庭点餐系统

家人用手机浏览器点餐，家里阿姨实时看到每个人点的菜，每个菜可外链小红书/抖音看做法，并按天自动汇总「买菜清单」，阿姨一眼看清要买哪些。

- 零依赖（只用 Node 自带模块）、零数据库、单个 `data.json` 存储
- 实时推送（SSE），任一人点餐阿姨页面秒级刷新
- 移动端优先，适配 iPhone 视网膜屏

---

## 一、本地运行（先在自己电脑上试用）

需要 Node.js 18+（你已有）。

```bash
cd 家庭点餐系统
node server.js
```

打开浏览器访问 `http://localhost:3000`。手机和电脑在同一 WiFi 下，手机访问你电脑的局域网地址（如 `http://192.168.x.x:3000`）也能用。

> 停止：在终端按 `Ctrl+C`。

---

## 二、部署到 Render 免费云（24 小时可用、Mac 可关机）

部署后全家手机随时能开（出门也能点），只需一个免费 Render 账号，**无需信用卡**。

### 第 1 步：把代码推到 GitHub
1. 注册 GitHub（免费）：https://github.com
2. 新建一个**私有**仓库，比如 `family-order`
3. 把 `家庭点餐系统/` 整个文件夹内容推上去（含 `server.js`、`public/`、`package.json`、`render.yaml`）

### 第 2 步：用 Render 一键部署
1. 注册 Render（免费）：https://render.com
2. 登录后点 **New → Blueprint**，授权 GitHub，选择刚才的仓库
3. Render 会读取 `render.yaml`，自动建一个 **Free** Web 服务
4. 点 **Apply**，等几分钟构建完成

### 第 3 步：拿到网址给家人
- 部署完成后，Render 会给你一个地址，形如 `https://family-order-xxxx.onrender.com`
- 把地址发到家庭群，家人用手机 Safari/微信浏览器打开即可
- **建议**：手机打开后点「分享 → 添加到主屏幕」，就像装了一个 App

> 免费层说明：长时间没人访问会「休眠」，下次打开要等约 30 秒唤醒，正常。建议使用「管理 → 导出备份」定期存一份数据（免费云盘极偶尔会重置实例，备份可一键恢复）。

## 三、使用说明

四个底部标签：

1. **点餐**：选「我是谁」→ 选早/午/晚 → 从菜谱里点菜（可填备注、点做法链接跳小红书/抖音）。已点的菜显示在下方，可删/改备注。
2. **阿姨总览**：按早/午/晚、按人列出全家点的菜，实时刷新；可「标记已做」。
3. **买菜清单**：当天所有订单的食材自动汇总（同名同单位会累加），阿姨打勾「已买」一目了然。
4. **管理**：增删成员、增删菜谱（菜名、适用餐次、小红书/抖音链接、所需食材）、设置管理页 PIN、导出/导入备份。

### 数据存在哪
所有数据在服务器上的 `data.json`。本地运行时就在项目目录里；部署到 Render 后存在云端实例（用导出备份可下载到本地）。

---

## 四、常见问题

- **家人打不开？** 确认手机和服务器在同一网络（本地）或网址正确（云端）。本地还需 Mac 允许「传入连接」。
- **想换端口？** 本地运行用 `PORT=8080 node server.js`。
- **想恢复备份？** 管理页 → 导入备份，选之前导出的 json 文件。
- **隐私？** 本地运行数据全在你家；云端运行数据在你自己的 Render 实例里，仅家庭成员知道网址即可访问（可设管理页 PIN 防娃乱改菜谱）。
